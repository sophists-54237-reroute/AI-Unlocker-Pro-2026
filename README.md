### Is there an automatic update feature for OmniPatch itself?

### Can I use OmniPatch on macOS or Linux?

No, OmniPatch is a Windows-only desktop utility developed specifically for the Windows environment.

### What should I do if the patcher isn't working?

Ensure you are running as administrator, check your anticomponent exclusions, and confirm you have the latest version from our GitHub repository.
